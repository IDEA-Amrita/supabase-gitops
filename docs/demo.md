## 1. Five-Minute Local Evaluation Walkthrough

Want to verify this repository locally before configuring GitHub Actions? You can run the entire migration lifecycle test and RLS behavioral audit locally in under 60 seconds using Docker:

```bash
# 1. Clone your repository
git clone https://github.com/<your-username>/supabase-gitops.git
cd supabase-gitops

# 2. Run the automated migration lifecycle integration test
chmod +x scripts/test_local_migrations.sh
./scripts/test_local_migrations.sh
```

**What this executes locally:**
1. Starts a fresh `postgres:17-alpine` container with standard Supabase roles (`anon`, `authenticated`, `service_role`).
2. Applies all version-controlled migrations from clean baseline.
3. Inserts deterministic seed records from `supabase/seed.sql`.
4. Re-applies migrations to prove idempotency.
5. Injects an intentionally broken migration to verify safe failure handling and rollback.
6. Asserts table counts, foreign keys, and indexes.
7. Cleanly destroys test resources.

```bash
# 3. Run the Disaster Recovery Negative Test Suite
chmod +x scripts/test_backup_negative.sh
./scripts/test_backup_negative.sh
```

**What this executes locally:**
- Verifies GPG AES-256 rejects incorrect passphrases with non-zero exit code.
- Verifies corrupted/truncated archives are rejected prior to restore.
- Verifies 0-byte dumps are caught and aborted.
- Verifies runner cleanup traps destroy all decrypted plaintext files even on failure.
